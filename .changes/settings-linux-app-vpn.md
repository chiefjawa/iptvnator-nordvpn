highlight: App-only NordVPN on Linux
---

Set up NordVPN with an access token to protect only IPTVnator and its players on Linux. Settings show the public IP; startup confirms a verified connection or warns if it cannot be checked. Requires the VPN helper service. Connecting restarts the player; disconnecting closes it. LAN remote control and self-installing updates are unavailable while connected.
